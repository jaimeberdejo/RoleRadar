## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Job (texto de oferta de fuente externa vía n8n) → prompt LLM | Untrusted: la oferta es DATO, no instrucción. El system prompt fija la tarea; la oferta va en sección <oferta> delimitada |
| ANTHROPIC_API_KEY (entorno) → SDK Anthropic | Secreto: lo lee el SDK del entorno; nunca se referencia/loggea en el código |
| LLM → LLMJobAssessment (sub-scores) | Output no confiable: clampeado a 0-100 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | Prompt injection vía descripción de la oferta (la oferta intenta sobrescribir las reglas de scoring) | mitigate | system prompt es cadena fija sin f-string de contenido externo; la oferta va en sección XML <oferta> delimitada del mensaje user; el LLM solo controla los 4 campos del LLMJobAssessment (no score_total/recommendation) |
| T-03-09 | Information Disclosure | Fuga de ANTHROPIC_API_KEY en código o logs | mitigate | la clave la lee el SDK de Anthropic del entorno; nunca se referencia en llm.py; logger.info solo loggea job.id/score/recommendation (no secretos ni el prompt completo) |
| T-03-01 | Tampering | sub-scores del LLM fuera de 0-100 | mitigate | Field(ge=0,le=100) en LLMJobAssessment + max_retries=2; score_total final clampeado con max(0,min(100,round(raw))) |
| T-03-10 | Elevation | LLM forzando recommendation/skip directamente | mitigate | recommendation es 100% determinista (bandas + override); LLMJobAssessment no tiene campo recommendation |
</threat_model>
