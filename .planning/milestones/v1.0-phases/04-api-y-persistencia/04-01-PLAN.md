## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | get_cached_cv_profile lee `{hash}.json` del cache dir | mitigate | El hash de _current se generó con pdf_hash (sha256, validado por _HEX_RE en Fase 1); leer solo data/.cache; no construir rutas con input de usuario directo |
| T-04-02 | Information Disclosure | ANTHROPIC_API_KEY en build_instructor_client | mitigate | La key se lee del entorno por el SDK Anthropic; nunca se referencia en código (patrón Fases 1-3 preservado) |
