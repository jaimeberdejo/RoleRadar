## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| datos de oferta (potencialmente de n8n/fuentes externas) → SQL | title/company/url/score_json se escriben en SQLite |
| env (SUPABASE_URL/KEY, SQLITE_DB_PATH) → selección de backend | credenciales y rutas desde el entorno |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Tampering | upsert_scored_jobs / was_seen / get_history construyen SQL | mitigate | SOLO consultas parametrizadas con placeholders `?`; NUNCA interpolación de strings en SQL (cubre SQL injection vía datos de oferta) |
| T-04-06 | Information Disclosure | credenciales Supabase | mitigate | SUPABASE_URL/SUPABASE_KEY leídas del entorno en get_storage_backend; nunca hardcodeadas |
| T-04-07 | Tampering | first_seen sobreescrito por error en upsert | mitigate | ON CONFLICT DO UPDATE SET excluye first_seen explícitamente (no INSERT OR REPLACE); test test_upsert_preserva_first_seen lo verifica |
</threat_model>
