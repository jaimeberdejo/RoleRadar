<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upload multipart (PDF) → API | fichero no confiable cruza en /cv/parse |
| body JSON (offers, jobs) → API | payloads de oferta potencialmente mal formados |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Denial of Service / Tampering | UploadFile en /cv/parse | mitigate | Validar content_type (rechazar no-PDF con 400) y sanity de tamaño; los bytes nunca se escriben a disco con nombre controlado por el cliente (cache por hash sha256 de Fase 1) |
| T-04-09 | Denial of Service | offers/jobs mal formados en el body | mitigate | normalize_jobs es batch-resiliente (una oferta mala → errors); /jobs/score envuelve cada score_job en try/except → un job malo no tumba el batch ni produce 500 (API-07) |
| T-04-10 | Tampering | prompt injection vía contenido de oferta en scoring | accept | scoring/llm.py (Fase 3) usa system prompt fijo + oferta en sección XML `<oferta>`; patrón preservado, no se altera en este plan |
</threat_model>
