      def parse_cv(pdf_bytes: bytes) -> CVProfile:
          """
          Interfaz pública de la fase.
          1. Comprueba caché por sha256 del contenido del PDF.
          2. Si hay caché: la devuelve sin tocar el LLM.
          3. Si no: extrae texto con pymupdf → LLM (instructor) → cachea → devuelve.
          """
          h = pdf_hash(pdf_bytes)
          cached = load_cached_profile(h)
          if cached is not None:
              return cached
          raw_text = extract_text_from_pdf(pdf_bytes)
          client = build_instructor_client()
          profile = extract_cv_profile(raw_text, client)
          save_cached_profile(h, profile)
          return profile

    public interface — keep the docstring, append:

      __all__ = ["parse_cv"]

| Boundary | Description |
|----------|-------------|
| caller → parse_cv | Untrusted PDF bytes enter the full pipeline |
| parser → cache (disk) | Extracted CVProfile (PII) persisted under CV_CACHE_DIR |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Denial of Service | parse_cv on a text-less/malformed PDF | mitigate | extractor raises a clear ValueError that propagates out of parse_cv (no silent hang); cache check happens first so repeat malformed input is cheap |
| T-01-10 | Information Disclosure | cached CVProfile (PII) written to disk | mitigate | CV_CACHE_DIR defaults to data/.cache (gitignored per Plan 01); tests redirect to tmp_path to avoid leaking fixture PII into real cache |
| T-01-11 | Tampering | test cache contamination causing false greens | mitigate | every parser test sets CV_CACHE_DIR=tmp_path; no test writes to the real data/.cache |
</threat_model>
