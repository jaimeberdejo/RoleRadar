<objective>
El endpoint principal de n8n: POST /jobs/process que recibe ofertas crudas de varias fuentes,
ejecuta normalización + dedup + scoring de punta a punta, devuelve las ofertas únicas puntuadas
y ORDENADAS por score_total desc, marcando ya_visto (computado con was_seen ANTES de persistir),
y persiste todo. Más GET /jobs/history (paginable). Más los tests e2e con LLM+embedder mockeados
y storage temporal que verifican orden, ya_visto en el segundo run, persistencia y resiliencia.

Purpose: Es la pieza que cierra la Fase 4 — junta las tres fases anteriores en un solo contrato
HTTP que n8n llama a diario. El control de ya-vistas (STORE-03) es lo que evita que n8n repita
ofertas entre días. El orden por score_total y la resiliencia de batch cumplen API-04 y API-07.
Output: app/api/routes/jobs.py ampliado con /jobs/process + /jobs/history + modelos; main.py ya
incluye el router jobs (Plan 03); tests/api/test_process.py verde.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| n8n → POST /jobs/process | ofertas crudas de varias fuentes (no confiables) cruzan en el body |
| /jobs/process → storage (SQLite) | datos de oferta + score se persisten |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Denial of Service | offers mal formadas en cualquier source de /jobs/process | mitigate | normalize_jobs batch-resiliente + try/except por job en el bucle de scoring → un job malo va a errors, nunca 500 (test test_process_oferta_malformada_va_a_errors) |
| T-04-12 | Tampering | prompt injection vía descripción de oferta hacia el LLM de scoring | accept | scoring/llm.py (Fase 3) usa system prompt fijo + oferta en `<oferta>` XML; /jobs/process no altera ese contrato |
| T-04-13 | Tampering | SQL con datos de oferta al persistir | mitigate | upsert_scored_jobs usa placeholders parametrizados (Plan 02, T-04-05); /jobs/process no construye SQL directamente |
| T-04-14 | Information Disclosure | GET /jobs/history expone histórico sin auth | accept | herramienta personal en localhost/red privada; sin datos de terceros; documentado en 04-CONTEXT.md y README (Fase 5) |
</threat_model>
