    Cosine-to-score mapping:
      - BGE-M3 vectors are L2-normalized → dot(a, b) gives cosine in [-1.0, 1.0]
      - In practice, positive-document cosines are in [0.0, 1.0]
      - Linear map: score = int(round(max(0.0, cosine) * 100))
      - Example: cosine 0.72 → 72; cosine -0.1 (rare) → 0; cosine 1.0 → 100
      Document the mapping in the module docstring as a visible table.

| Boundary | Description |
|----------|-------------|
| job description → embedder.embed() | Job description text (untrusted, external) is passed to the embedder as data — no code execution path |
| cv_text → embedder.embed() | CV text (trusted, user-controlled) — no injection risk |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
