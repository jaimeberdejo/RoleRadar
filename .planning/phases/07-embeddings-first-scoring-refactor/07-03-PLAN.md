    ```python
    from __future__ import annotations
    import dataclasses
    import logging
    import re

    logger = logging.getLogger(__name__)


    @dataclasses.dataclass
    class SeniorityResult:
        encaje_seniority: int      # 0-100
        seniority_nota: str        # human-readable note, never empty
        anos_requeridos: float | None  # parsed from description, None if not found
    ```

    REGEX patterns (compile at module level, not inside the function):
    ```python
    # Matches: "5+ years", "5 years", "at least 5 years", "5 años", "5+ años",
    #           "minimum 5 years", "5-7 years" (takes the lower bound)
    _RE_ANOS = re.compile(
        r"(\d+)\s*\+?\s*(?:to\s*\d+\s*)?(?:years?|años?)\s*(?:of\s*)?(?:experience|experiencia)?",
        re.IGNORECASE,
    )
    # Level keywords → approximate years mapping
    _NIVEL_ANIOS: dict[str, float] = {
        "junior": 1.0,
        "mid-level": 3.0,
        "mid level": 3.0,
        "senior": 5.0,
        "lead": 7.0,
        "principal": 9.0,
        "staff": 8.0,
        "director": 10.0,
    }
    ```

    Function `_parse_anos_requeridos(description: str) -> float | None`:
    1. Try _RE_ANOS first. If found, return float of the first captured group.
    2. If not found, check each key of _NIVEL_ANIOS in description.lower(). Return first match value.
    3. Return None if no signal found.

    Function `evaluar_seniority(job_description: str, anios_candidato: float | None) -> SeniorityResult`:

    Step 1: anios_candidato is None → neutral path
      - Return SeniorityResult(encaje_seniority=50, seniority_nota="Experiencia del candidato desconocida (CV sin años estimados)", anos_requeridos=None)

    Step 2: parse anos_requeridos from description
      - If None (no signal in description): return SeniorityResult(encaje_seniority=75, seniority_nota="Sin requisito de años explícito en la oferta", anos_requeridos=None)
        Reasoning: no explicit requirement → generous assumption (not max 100, because we don't know).

    Step 3: compare anos_requeridos vs anios_candidato
      Ratio = anios_candidato / anos_requeridos
      Score mapping (justify in docstring):
        ratio >= 1.5 → 100  (exceeds requirement significantly → max)
        ratio >= 1.0 → 85   (meets or slightly exceeds)
        ratio >= 0.7 → 65   (close but under — "requisitos inflados" per CLAUDE.md rule 3)
        ratio >= 0.5 → 45   (notably below)
        ratio >= 0.3 → 25   (significantly below)
        ratio < 0.3  → 10   (very junior for a senior role)

      Note: set seniority_nota accordingly:
        ratio >= 1.0: f"El candidato tiene {anios_candidato:.0f} años vs {anos_requeridos:.0f} requeridos — cumple"
        ratio < 1.0:  f"El candidato tiene {anios_candidato:.0f} años vs {anos_requeridos:.0f} requeridos — por debajo del requisito"

    Step 4: clamp score to [0, 100] and return SeniorityResult.

    Module docstring must explain:
    - Purpose and why deterministic (no LLM)
    - The None=neutral=50 decision (STATE blocker)
    - The ratio mapping table
    - Why low seniority doesn't force skip (CLAUDE.md rule 3: requisitos inflados)
    - No app.dedup imports (stdlib only)

    Type hints on all functions. Logging at DEBUG for parsed anos_requeridos, ratio, score.
