    ```python
    import dataclasses
    import logging
    import unicodedata

    logger = logging.getLogger(__name__)


    @dataclasses.dataclass
    class DealBreakerResult:
        hit: bool
        cual: str | None  # None if hit=False; matched deal_breaker string(s) if hit=True
    ```

    Private helper `_normalizar(text: str) -> str`:
      Replicate the NFD pattern from location.py (do NOT import location.py — that would
      create a cross-dependency between scoring submodules):
      ```python
      def _normalizar(text: str) -> str:
          nfd = unicodedata.normalize("NFD", text.lower().strip())
          return "".join(c for c in nfd if unicodedata.category(c) != "Mn")
      ```

    Public function signature:
    ```python
    def detectar_deal_breaker(
        job_text: str,
        deal_breakers: list[str],
    ) -> DealBreakerResult:
    ```

    Implementation:
    1. Guard: if not job_text or not deal_breakers → return DealBreakerResult(hit=False, cual=None)
    2. job_norm = _normalizar(job_text)
    3. hits: list[str] = []
    4. For each db in deal_breakers:
         db_norm = _normalizar(db)
         if db_norm in job_norm:
             hits.append(db)  # append the ORIGINAL (non-normalized) string for readability
    5. If hits:
         cual = "; ".join(hits)
         log at INFO: f"Deal-breaker detectado: {cual}"
         return DealBreakerResult(hit=True, cual=cual)
    6. Else:
         return DealBreakerResult(hit=False, cual=None)

    Helper for scorer.py: document that `job_text` should be built as
    `f"{job.title} {job.description}"` (both fields, so title-based deal-breakers also fire).

    - Purpose: deterministic text deal-breaker detection (no LLM)
    - Why substring not word-boundary: deal_breakers are natural language phrases
      ("exige 5+ años de experiencia") that contain punctuation and numbers — word-boundary

    - NFD normalization replication (not importing location.py — avoids cross-module coupling)
    - Multiple hits policy: all appended, joined with "; "
    - On hit, scorer.py must set recommendation=skip (hard filter, CLAUDE.md rule 4)
