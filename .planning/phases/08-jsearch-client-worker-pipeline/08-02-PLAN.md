Function 1: `fetch_jsearch_query`
Signature:
```python
def fetch_jsearch_query(
    query: str,
    *,
    date_posted: str = "3days",
    num_pages: int = 1,
    country: str = "es",
    client: httpx.Client | None = None,
) -> list[dict]:
```
- Read `RAPIDAPI_KEY` from `os.environ.get("RAPIDAPI_KEY", "")` inside the function
  (not at module level — avoids import-time env requirement).
- Build headers dict with X-RapidAPI-Key and X-RapidAPI-Host.
- Build params: `{"query": query, "page": "1", "num_pages": str(num_pages),
  "date_posted": date_posted, "country": country}`.
- If `client is None`, create one: `_client = httpx.Client(timeout=DEFAULT_TIMEOUT)`.
  Wrap in try/finally: `finally: if client is None: _client.close()`.
- Call `_client.get(JSEARCH_BASE, headers=headers, params=params)`.
- On status_code == 429: `logger.warning("JSearch 429 for query=%r — skipping", query)`
  and return `[]`.
- Call `resp.raise_for_status()`. Parse `resp.json().get("data", [])` and return it.
- Catch `httpx.HTTPError as exc`: `logger.warning("JSearch HTTP error for query=%r: %s",
  query, exc)` and return `[]`. NEVER raise (per-query isolation invariant).
