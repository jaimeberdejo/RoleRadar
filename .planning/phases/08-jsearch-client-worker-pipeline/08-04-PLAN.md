**`run_pipeline` function:**
```python
def run_pipeline(
    *,
    storage=None,      # Storage | None — if None, construct default SQLiteStorage
    embedder=None,     # Embedder | None — if None, construct BgeM3Embedder (heavy)
    llm_client=None,   # instructor.Instructor | None — for LLM enrichment
    profile_path: str | Path | None = None,  # for tests
) -> PipelineResult:
```

Implementation steps (follow RESEARCH.md section 5 exactly):

1. **Build dependencies** if not injected:
   - `storage`: `from app.storage import get_storage_backend; storage = get_storage_backend()`
   - `embedder`: `from app.dedup.embedder import BgeM3Embedder; embedder = BgeM3Embedder()`
   - Both use deferred imports inside the function.

2. **Load user profile + CV profile:**
   ```python
   from app.config.loader import load_user_profile
   user_profile = load_user_profile(path=profile_path)
   cv_profile = _get_cv_profile(storage)
   ```

3. **Load settings + determine date_posted:**
   ```python
   settings = storage.get_settings()
   date_posted = "month" if _is_first_run(storage) else "3days"
   settings = {**settings, "date_posted_override": date_posted}
   ```
   Build the list of queries from `user_profile.ranking_puestos`:
   ```python
   queries = [p.titulo for p in user_profile.ranking_puestos]
   ```

4. **Fetch:**
   ```python
   started_at = _now_iso()
   result = PipelineResult()
   raw_jobs = fetch_all_queries(queries, settings)
   result.fetched = len(raw_jobs)
   ```

5. **Normalize** (batch-resilient, per CLAUDE.md requirement):
   ```python
   jobs, norm_errors = normalize_jobs(raw_jobs, source="jsearch")
   result.errors.extend(f"normalize: {e}" for e in norm_errors)
   ```

6. **Deduplicate within batch:**
   ```python
   deduped = deduplicate(jobs, embedder=embedder,
                         umbral=float(settings.get("dedup_threshold", "0.85")))
   result.deduped = len(deduped)
   ```

7. **Dedup against stored (hash check — no re-embedding):**
   ```python
   new_jobs = [j for j in deduped if not storage.was_seen(j.id)]
   result.scored = len(new_jobs)
   ```

8. **Score new jobs (per-job error isolation):**
   ```python
   scored_list: list[ScoredJob] = []
   for job in new_jobs:
       try:
           job_score = score_job(job, user_profile, cv_profile, embedder,
                                 client=llm_client)
           scored_list.append(ScoredJob(job=job, score=job_score))
       except Exception as exc:
           logger.warning("score_job failed for job_id=%s: %s", job.id, exc)
           result.errors.append(f"score_job({job.id}): {exc}")
   result.scored_jobs = scored_list
   ```

9. **Upsert all scored jobs:**
   ```python
   if scored_list:
       storage.upsert_scored_jobs(scored_list)
   result.new_seen = len(scored_list)
   ```

10. **Record run:**
    ```python
    finished_at = _now_iso()
    storage.record_run(
        started_at=started_at,
        finished_at=finished_at,
        fetched=result.fetched,
        deduped=result.deduped,
        scored=result.scored,
        new_seen=result.new_seen,
        errors=result.errors if result.errors else None,
    )
    ```

11. **Structured log summary:**
    ```python
    logger.info(
        "Pipeline complete: fetched=%d deduped=%d scored=%d new=%d errors=%d",
        result.fetched, result.deduped, result.scored, result.new_seen,
        len(result.errors),
    )
    return result
    ```

IMPORTANT: The entire body is NOT wrapped in a broad try/except that suppresses
the exception. APScheduler catches exceptions itself and emits EVENT_JOB_ERROR
(RESEARCH.md section 4). Only per-job exceptions in step 8 are caught. Fatal
errors (DB unavailable, profile missing) should propagate naturally.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JSearch API response → normalize_jobs | Untrusted string fields (job_title, employer_name, job_description) enter the pipeline |
| jobs table → score_job | Stored job data re-used in scoring — stable SHA-256 IDs, not user-controlled |
| profile.yaml → run_pipeline | YAML file loaded from disk; parsed with yaml.safe_load (no code execution) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-09 | Tampering | pipeline untrusted JSearch fields → DB | mitigate | jsearch_mapper uses `.get()` fallbacks; all fields are stored as-is in Job.raw (JSONB TEXT); SQL uses parameterized queries in upsert_scored_jobs — no string interpolation into SQL |
| T-08-10 | Tampering | job_description prompt injection → LLM scoring | mitigate | scorer.py uses fixed XML prompt template (`<oferta>` section) as anti-injection boundary (decision from v1.0 State: "fixed system prompt: offer in XML <oferta> section") |
| T-08-11 | Denial of Service | BGE-M3 model load per pipeline call | accept | Embedder injected via run_pipeline(embedder=...) parameter; worker constructs one BgeM3Embedder and passes it; the UI will use @st.cache_resource (Phase 10) |
| T-08-12 | Information Disclosure | errors list in PipelineResult / runs table | accept | Error strings contain job IDs (SHA-256 hashes) and exception messages — no PII, no API keys; log level WARNING |
| T-08-13 | Elevation of Privilege | worker.py APScheduler job execution | accept | Worker runs as the same process user; no privilege escalation — single-user local tool |
</threat_model>
