    ```python
    from __future__ import annotations
    import json
    from pathlib import Path
    from app.models.schemas import UserProfile, PesosScoring
    from app.config.loader import load_user_profile

    def build_effective_profile(settings: dict, profile_path: str | Path | None = None) -> UserProfile:
        base = load_user_profile(path=profile_path)
        new_pesos = PesosScoring(
            puesto=float(settings.get("score_weight_puesto", "0.35")),
            skills=float(settings.get("score_weight_skills", "0.30")),
            ubicacion=float(settings.get("score_weight_ubicacion", "0.20")),
            seniority=float(settings.get("score_weight_seniority", "0.15")),
        )  # PesosScoring validator raises ValueError if sum != 1.0 (D-08)
        raw_db = settings.get("deal_breakers", "")
        try:
            new_deal_breakers = json.loads(raw_db) if raw_db else base.deal_breakers
            if not isinstance(new_deal_breakers, list):
                new_deal_breakers = base.deal_breakers
        except (json.JSONDecodeError, TypeError):
            new_deal_breakers = base.deal_breakers
        return base.model_copy(update={"pesos": new_pesos, "deal_breakers": new_deal_breakers})
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| settings table → scorer | UI-written settings (weights, deal_breakers JSON) cross into scoring via the overlay — must be validated/parsed defensively |
| stored job rows → Job reconstruction | DB rows feed rescore's Job() — a malformed/None remote must not crash the batch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02-01 | Tampering | deal_breakers JSON from settings | mitigate | build_effective_profile wraps json.loads in try/except + isinstance(list) check → bad JSON falls back to profile.yaml, never raises into the worker |
| T-10-02-02 | Denial of Service | invalid pesos crash worker mid-run | mitigate | PesosScoring validator runs at overlay construction time; Settings page (Plan 06) validates before persisting; overlay raises ValueError early, not deep in scoring |
| T-10-02-03 | Tampering | None remote in stored row → RemoteJob(None) crash | mitigate | rescore uses `RemoteJob(row["remote"]) if row.get("remote") else RemoteJob.unknown`; per-job try/except isolates any residual failure |
| T-10-02-04 | Information Disclosure | core imports streamlit (breaks invariant) | mitigate | Acceptance criterion asserts streamlit not in sys.modules after importing the new modules |
</threat_model>
