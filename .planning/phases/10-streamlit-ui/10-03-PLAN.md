    Implement exactly:
    ```python
    from __future__ import annotations
    import threading
    import streamlit as st
    from app.dedup.embedder import BgeM3Embedder
    from app.storage import get_storage_backend

    @st.cache_resource
    def get_embedder() -> BgeM3Embedder:
        """One BgeM3Embedder per Streamlit process (UI-10 / SC7). Reused by Run now + Re-score."""
        return BgeM3Embedder()

    @st.cache_resource
    def get_storage():
        """One initialized SQLiteStorage per process."""
        return get_storage_backend()

    def get_effective_profile(profile_path=None):
        from app.profile_overlay import build_effective_profile  # noqa: PLC0415
        settings = get_storage().get_settings()
        return build_effective_profile(settings, profile_path)

    # ── Non-blocking Run now (D-04/D-05/D-06) ───────────────────────────────
    _RUN_LOCK = threading.Lock()
    _RUN_STATUS: dict = {"running": False, "result": None, "error": None}

    def _run_pipeline_thread(storage, embedder, profile_path) -> None:
        """Runs in a background thread. NEVER calls st.* (no ScriptRunContext)."""
        from app.pipeline import run_pipeline  # noqa: PLC0415
        try:
            result = run_pipeline(storage=storage, embedder=embedder, profile_path=profile_path)
            with _RUN_LOCK:
                _RUN_STATUS["result"] = result
        except Exception as exc:  # noqa: BLE001
            with _RUN_LOCK:
                _RUN_STATUS["error"] = str(exc)
        finally:
            with _RUN_LOCK:
                _RUN_STATUS["running"] = False

    def start_run(profile_path=None) -> bool:
        """Launch a pipeline run in the background. Returns False if one is already running (D-06)."""
        with _RUN_LOCK:
            if _RUN_STATUS["running"]:
                return False
            _RUN_STATUS["running"] = True
            _RUN_STATUS["result"] = None
            _RUN_STATUS["error"] = None
        t = threading.Thread(
            target=_run_pipeline_thread,
            args=(get_storage(), get_embedder(), profile_path),
            daemon=True,
        )
        t.start()
        return True
    ```
    Pass the `@st.cache_resource` embedder into the thread (D-05: NO 2nd BGE-M3 in the UI process).
    Use the lock for all _RUN_STATUS mutations (RESEARCH Pitfall recommendation, gotcha #3).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Streamlit thread → background thread | The bg thread has no ScriptRunContext; it must never call st.* and must not write to st.session_state |
| ui → app | One-directional import (ui imports app); app must never import ui (import-cleanliness invariant) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03-01 | Tampering | bg thread writing to wrong session via st.* | mitigate | _run_pipeline_thread contains zero st.* calls (acceptance criterion greps the thread body); status flows through a module dict only |
| T-10-03-02 | Denial of Service | double "Run now" → two pipelines, SQLite contention | mitigate | start_run() checks+sets running under a lock and returns False on a second concurrent start (D-06) |
| T-10-03-03 | Resource Exhaustion | a 2nd BGE-M3 (~2-4 GB) loads in the UI process | mitigate | get_embedder() is @st.cache_resource and the cached instance is injected into run_pipeline (D-05); test asserts singleton identity |
| T-10-03-04 | Information Disclosure | app/ pulls in streamlit transitively | accept | This plan is the ui layer (streamlit expected); core import-cleanliness is guarded in Plan 02 and tests/test_import_cleanliness.py |
</threat_model>
