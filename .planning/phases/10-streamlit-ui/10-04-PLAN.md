    ```python
    from __future__ import annotations
    from app.cv.cache import pdf_hash, load_cached_profile, save_cached_profile
    from app.cv.parser import parse_cv
    from app.models.schemas import CVProfile

    def resolve_cv_profile(pdf_bytes: bytes, *, client=None) -> tuple[CVProfile, bool]:
        """Cache-first CV resolution. Returns (profile, was_cached).

        was_cached=True → loaded from disk cache (no LLM call); False → freshly parsed+saved.
        Satisfies SC1: same PDF bytes → same hash → cache hit → no re-parse.
        """
        h = pdf_hash(pdf_bytes)
        cached = load_cached_profile(h)
        if cached is not None:
            return cached, True
        profile = parse_cv(pdf_bytes, client=client)
        save_cached_profile(h, profile)
        return profile, False
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser file upload → parse_cv | Uploaded PDF is attacker-controlled bytes |
| UI form input → settings table | Search params written to the cross-process config bus the worker reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04-01 | Tampering | path traversal via CV cache filename | mitigate | cache key is pdf_hash() (sha256 hex) and cache.py `_validate_hash` rejects non-hex-64 — no traversal possible; UI never names files directly |
| T-10-04-02 | Tampering | non-PDF upload | mitigate | st.file_uploader(type=["pdf"]) restricts at the widget; parse_cv reads bytes only, never executes |
| T-10-04-03 | Tampering | malformed search settings break the worker | mitigate | values are coerced to strings via set_setting; date_posted constrained to a fixed selectbox option set; remote_only serialized to "true"/"false" |
| T-10-04-04 | Information Disclosure | CV contents rendered to a shared session | accept | single-user local tool (CLAUDE.md); no multi-user session leakage in scope |
</threat_model>
