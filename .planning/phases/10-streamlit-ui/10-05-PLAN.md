    ```python
    from __future__ import annotations
    import pandas as pd

    def filter_history(history: list[dict], min_score: int, recommendations: list[str]) -> list[dict]:
        return [r for r in history
                if r["score_total"] >= min_score and r["recommendation"] in recommendations]

    def build_results_df(history: list[dict]) -> pd.DataFrame:
        return pd.DataFrame([
            {"Título": r["title"], "Empresa": r["company"], "Score": r["score_total"],
             "Recomendación": r["recommendation"], "_idx": i}
            for i, r in enumerate(history)
        ])

    def run_status_label(status: dict) -> tuple[str, str]:
        if status.get("running"):
            return "running", "Buscando y puntuando ofertas…"
        if status.get("error"):
            return "error", f"Error en el run: {status['error']}"
        if status.get("result") is not None:
            r = status["result"]
            return "done", f"Run completado — {r.scored} nuevas ofertas puntuadas."
        return "idle", ""
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored job rows → page render | DB rows (incl. score JSON) rendered into the browser |
| env vars → page | OPENAI_API_KEY presence drives the cost warning |
| user click → background pipeline | Run now / Re-score trigger heavy work |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05-01 | Information Disclosure | OPENAI_API_KEY value rendered in cost warning | mitigate | Only `bool(os.getenv("OPENAI_API_KEY"))` is shown ("✓/✗"); the value is never passed to st.* — acceptance criterion checks this |
| T-10-05-02 | Denial of Service | double Run now → two pipelines | mitigate | button disabled while _RUN_STATUS["running"]; start_run() returns False on a second concurrent start (Plan 03/D-06) |
| T-10-05-03 | Denial of Service | Re-score on huge history → many LLM calls / cost | mitigate | cost/count confirmation shown before running (N jobs, OpenAI presence); rescore_stored has a limit cap |
| T-10-05-04 | Tampering | missing dict key (url/remote) → KeyError crash | mitigate | detail view uses .get()/presence checks; absent url is skipped silently, never KeyErrors |
| T-10-05-05 | Information Disclosure | background thread writes to wrong session via st.* | mitigate | the thread lives in services.py (Plan 03) and never calls st.*; the page only reads _RUN_STATUS |
</threat_model>
