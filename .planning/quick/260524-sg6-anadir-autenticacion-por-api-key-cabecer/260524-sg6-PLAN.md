Create `app/api/auth.py`:

```python
"""Autenticación por cabecera X-API-Key para el servicio BuscadorDeEmpleo.

Diseño:
  - API_KEY ausente del entorno → autenticación DESACTIVADA. Cualquier petición
    pasa. En el arranque (ver log_auth_startup_warning) se emite un WARNING ruidoso.
    Esto mantiene los tests existentes verdes sin modificarlos (no exportan API_KEY).
  - API_KEY presente → se exige en todas las rutas salvo GET /health. Cabecera
    ausente o incorrecta → 401 con el mismo mensaje (no se distingue entre los dos
    casos — anti information disclosure). Comparación con secrets.compare_digest
    para evitar timing attacks.

Uso en main.py:
    app = FastAPI(..., dependencies=[Depends(verify_api_key)])
    # /health está en un router sin dependencias globales — ver profile.py
"""
from __future__ import annotations

import logging
import os
import secrets

from fastapi import Depends, HTTPException, Security
from fastapi.security import APIKeyHeader

logger = logging.getLogger(__name__)

_api_key_header = APIKeyHeader(name="X-API-Key", auto_error=False)


def verify_api_key(key: str | None = Security(_api_key_header)) -> None:
    """Dependency global: valida X-API-Key si API_KEY está configurada.

    - API_KEY ausente del entorno: siempre pasa (modo dev/test).
    - API_KEY presente: key debe coincidir; si no → HTTP 401.
      Se usa secrets.compare_digest para comparación en tiempo constante.
      El mismo 401 para cabecera ausente y para cabecera incorrecta
      (no revelar cuál es el error — anti information disclosure).
    """
    expected = os.environ.get("API_KEY", "")
    if not expected:
        # Auth desactivada — no hay clave configurada.
        return
    provided = key or ""
    if not secrets.compare_digest(provided, expected):
        raise HTTPException(
            status_code=401,
            detail={"type": "Unauthorized", "message": "Invalid or missing API key"},
        )


def log_auth_startup_warning() -> None:
    """Emite WARNING ruidoso si API_KEY no está configurada.

    Llamar desde lifespan (app/api/main.py) tras configure_logging()
    para que el mensaje aparezca con el formato correcto desde el inicio.
    """
    if not os.environ.get("API_KEY", ""):
        logger.warning(
            "API_KEY not set — authentication DISABLED, service is open. "
            "Set API_KEY in .env to protect all endpoints (except GET /health)."
        )
    else:
        logger.info("API_KEY configured — authentication ENABLED on all routes except GET /health.")
```

```python
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request as StarletteRequest
from starlette.responses import JSONResponse as StarletteJSONResponse

_PUBLIC_PATHS: frozenset[str] = frozenset({"/health"})


class ApiKeyMiddleware(BaseHTTPMiddleware):
    """Middleware que aplica la autenticación X-API-Key a todas las rutas
    excepto las de _PUBLIC_PATHS.

    Cuando API_KEY no está en el entorno → pasa todo sin tocar (modo dev/test).
    Cuando API_KEY está → exige la cabecera en rutas no exentas.
    """

    async def dispatch(self, request: StarletteRequest, call_next):
        expected = os.environ.get("API_KEY", "")
        if not expected or request.url.path in _PUBLIC_PATHS:
            return await call_next(request)
        provided = request.headers.get("X-API-Key", "")
        if not secrets.compare_digest(provided, expected):
            return StarletteJSONResponse(
                status_code=401,
                content={"error": {"type": "Unauthorized", "message": "Invalid or missing API key"}},
            )
        return await call_next(request)
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| n8n → API | n8n sends HTTP requests; without auth enforcement any caller on the network can hit all endpoints |
| client → /health | Public endpoint; acceptable (no data exposed, used by Docker healthcheck and n8n availability checks) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-sg6-01 | Spoofing | X-API-Key header | mitigate | secrets.compare_digest constant-time comparison prevents timing oracle attacks |
| T-sg6-02 | Information Disclosure | 401 response body | mitigate | Same message for missing vs wrong key ("Invalid or missing API key") — caller cannot distinguish the two cases |
| T-sg6-03 | Information Disclosure | /docs, /openapi.json, /redoc | mitigate | ApiKeyMiddleware runs before FastAPI routing, covers all paths including Swagger UI assets |
| T-sg6-04 | Elevation of Privilege | API_KEY unset in prod | accept | App emits loud WARNING at startup; responsibility of operator to set the key in production; behavior is documented |
| T-sg6-05 | Tampering | env var leak via error body | accept | Generic error handler (T-05-03) never leaks env vars; 401 body is static string literal |
</threat_model>
